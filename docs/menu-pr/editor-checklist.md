# Editor panel manual checklist (needs a signed-in session)

Pages panel -> "Sayfalar ve menü":
1. Open an existing one-page site whose menu lacks Hakkımızda / Hizmetlerimiz / İletişim: the suggestion card lists exactly the missing labels (e.g. "Hizmetlerimiz, İletişim").
2. Nothing changes in the header until the button is pressed; reload the editor: the site is untouched.
3. "Sayfaları üst menüye ekle": entries appear once, in order, preview header + mobile menu match; card disappears.
4. "Gerek yok": card disappears, reload and re-open another tab: it stays dismissed.
5. A site whose menu already holds 7 entries: no card, no additions.
6. A page switched off with its "Üst menüde göster" toggle is never re-added by the button.
7. Published site: after accepting, publish again; live header shows the same entries; before publishing it is unchanged.
8. Undo (Ctrl+Z) after accepting restores the previous menu.
